A · What it is and how it works

RAG Ultimate answers questions only from your documents, shows the exact evidence, checks its own numbers, and refuses rather than guesses. It runs fully offline (Ollama) or with cloud AI, and it has sign-in, roles, tenants and security checks on every request.

Architecture in one picture

Key idea: the UI and the API are only "front doors". Every rule (sign-in, permissions, guardrails, model choice) is enforced in RAGService on the server, so both doors are equally protected.

What happens when you upload a document

1 ValidateChecks the real type from the file's bytes, size, executables, macros, zip bombs
→
2 StoreOriginal kept once, identified by its content fingerprint
→
3 ReadPDF text, tables, equations, figures; Office/CSV/HTML/JSON; OCR for images and scans
→
4 ChunkShort passages with page and section kept
→
5 EmbedMeaning vector per passage
→
6 RegisterVersion, sensitivity (personal data → confidential), old version's indexes removed

What happens when you ask a question

#StageWhat it doesCost
1Input checksrate limit, prompt injection, harmful content, topic rules; personal data removed from the questionfree
2Permissionsonly your organisation's documents that your role may read, latest version onlyfree
3Understanding agentquestion type (lookup, summary, calculation, comparison, figure) + 2 search variantsfree
4Retrieval agentkeyword (BM25) + meaning + fuzzy search → combined (RRF) → reranked → best passagesfree (local)
5Model routerdrops unsuitable models (wrong mode, cloud for confidential documents, too small, failing) and picks onefree
6Reasoning agentthe AI answers only from those passages, citing each one [REF-n]; uses a calculator for maths1 AI call
7Verification + qualityevery number checked against its source; fixed once; still unsupported → answer withheldusually free
8Output checkshides secrets, blocks leaked instructions, masks personal data, removes unauthorised sourcesfree
9You seeanswer + evidence + ✓ Verified + "Why this model" + agent trace; everything is logged without your question text

  1. docker.com/products/docker-desktop → install with Use WSL 2 ticked → restart Windows.

Needs about 8 GB RAM free and 15 GB disk (image ~2 GB + the Ollama model ~5 GB).

cd "C:\Users\mvspc\Documents\anna\New folder\New folder\rag-ultimate-2.0.0\rag-ultimate-main"

C · User guide (with explanations)

Built-in help (start here inside the app)

The app explains itself. Open 🎓 Guide & Test Lab (first item in the sidebar):

  • ① Start here checks your setup (AI model, documents, OCR, database, sign-in, your role) and says how to fix each item.
  • ② How it works shows the upload pipeline and the question pipeline step by step, with where to see each step.
  • ③ Test Lab loads 4 sample documents with known answers and runs one-click, auto-checked tests: answers from PDF, Word, Excel and Markdown, a calculation, a question it must refuse, and safety tests (injection, secret extraction, harmful request, card number, no false alarm). ✅ pass · ❌ fail · ➖ not tested (for example, no AI model connected).
  • ④ Checklist lists manual tests on every other page.

Every page also has a ℹ️ What is this page? panel (what it is for, how to use it, what to try and what to expect), and every answer has 🧑‍🏫 How this answer was made, a plain-English story of the safety check, search, model choice, verification and quality decision. Switch these off with 🎓 Beginner help in the sidebar.

Signing in and roles

With AUTH_MODE=users everyone signs in. Roles decide what you can do:

RoleCanTypical person
viewerask questions about documents they may readstaff member
editor+ upload, relabel and delete own documents, run evaluationsdocument owner
admin+ users, safety policy, models, all documents, audit logyou

Five wrong passwords lock an account for 15 minutes. Each organisation (tenant) is completely separate.

Chat: asking and reading answers

Citations
[REF-2: TABLE p3] = evidence item 2, a table on page 3. Every fact in an answer points to one.
Evidence panel
Opens each cited passage: document, page, section, the exact text, table row or figure.
✓ Verified badge
Verified: all numbers match their sources. Partially verified: some couldn't be checked. Unverified: be careful; check the evidence.
Agent activity
Which agents ran and how long each took (understanding, retrieval, reasoning, verification, quality).
Why this model
Which AI answered and why the others were skipped (e.g. "sensitive data: cloud models not allowed").
Follow-ups & memory
"and at 85 °C?" understands the previous question. 👍/👎 feedback tunes the answer style.

Sidebar: Model mode (local / cloud / hybrid) and Model (automatic or a specific one). Confidential documents still never go to cloud models unless an admin allowed it.

Tips for good questions: name the symbol or unit ("max VIN at 25 °C"), ask one thing at a time, say "Summarize this document" for overviews, and use "calculate …" for maths (the AI uses a calculator tool).

Documents

  • Upload: PDF, DOCX, PPTX, XLSX, CSV, TXT, MD, HTML, JSON, PNG/JPG (up to 50 MB each). Scans and images are read with OCR.
  • Sensitivity: public · internal · confidential · restricted. The last two are answered by local AI only. Files with detected personal data become confidential automatically.
  • Versions: same file name with new content → version 2; the old version is no longer searched. The same content under another name → "already indexed" (stored once).
  • Access control: choose which roles may read each document (empty = everyone in your organisation).
  • Delete: removes all versions, search indexes and stored originals.
  • On/off switch: decide which documents the chat searches.

RAGRetrieval-Augmented Generation: find passages first, then answer from them.
Chunka short passage of a document; the unit that is searched and cited.
Embeddingnumbers describing a passage's meaning, for meaning-based search.
BM25 / fuzzykeyword scoring / approximate text matching; good for exact symbols and part numbers.
RRFReciprocal Rank Fusion: combines several rankings into one.
Rerankera small model that re-orders the top passages by relevance.
Grounded / verifiedevery statement and number is backed by a cited passage.
Prompt injectiontext trying to make the AI ignore its rules.
PIIpersonal data: e-mails, phone numbers, IDs, account numbers.
Tenanta separate organisation inside the app.
Profile (Docker)a named set of containers started together (local, hybrid, production, monitoring).
CIautomatic tests and scans that GitHub runs on every push.
